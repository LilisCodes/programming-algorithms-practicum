# Programming Algorithms Practicum

This repository contains my coursework, practical exercises, notes, and R programming implementations for the **Programming Algorithms Practicum**.

The practicum covers fundamental programming and algorithm concepts, data object types, data management, data visualization, descriptive statistics, probability, and statistical distributions using the R programming language.
